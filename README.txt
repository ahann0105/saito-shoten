齊藤商店 ホームページ更新版

【確認方法】
index.html をダブルクリックしてください。

【写真の入れ方】
1. images フォルダに写真を入れます。
2. script.js の各商品にある image: '' を変更します。
   例：image: 'images/yoyo01.jpg'

【メルカリURLの入れ方】
script.js の各商品にある url: '#' を、専用購入ページのURLに変更します。
